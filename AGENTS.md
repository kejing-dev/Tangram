# 七巧板 Tangram: project guidance

A wooden tangram on the desk for PICO OS 6 Shared Space (Spatial SDK BOM 6.1.9), package `io.embodit.tangramwood`, v0.1.2.
Design contract: spatial-app-factory `apps/tangram-wood/design-package.json` (v1.2, gate B passed), PRD and sample beside it.
Skeleton from the factory's KlotskiBox v0.1.1 (two containers, theme, sound pool, level gate, board-input template); the
tangram domain, scene and pages are new. 2026-11-10 user: 「七巧板也可以做，就是要给格子本身和间距大一点，不然空间交互容易点错」
→ profile D17 补, relaxed 2026-11-11 (「Relax to 2°」): every tap target ≥ 4 cm and ≥ 2° from the system's default
placement (volume 1.75 m ahead), counted after foreshortening; gaps ≥ max(1.5 cm, 0.3 × size). All sizes live in
`domain/Layout.kt` and are unit-tested (`LayoutTest`, `SceneTest`; tables in `app/build/reports/`). Design package v1.3.

## Surfaces
- **Tangram volume** (default container `TangramVolume`, Volumetric 1.30 × 0.78 × 0.32 m, fixed scale, gravity aligned,
  uniform resize). On a plinth, side by side and both leaning back 70°: the walnut tray (left) with the seven pieces at
  their homes, the walnut board (right) with the figure's shadow; the turn / flip tabs on a fixed rail under the board;
  a title plate above the board's top edge. u = 8.5 cm (2× a real 12 cm set),
  pieces 1.3 cm thick, maple face / cherry back (procedural extrusions + Canvas wood grain, no GLB — design assets).
- **Control window** (`TangramControl`, Planar 640 × 620 dp, `Placement.right(TangramVolume)`): native SpatialUI `TabBar`,
  four pages 拼 / 题库 / 规矩 / 设置; no page scrolls. [重开控制窗] closes and reopens beside the volume (D44);
  [退出应用] closes both containers, removes the tasks, exits the process.

## Tap targets (volume)
| Holder | What | Size |
|---|---|---|
| `piece:0..6` | the pieces (0,1 big · 2 middle · 3,4 small · 5 square · 6 parallelogram); convex-mesh collider = the visible shape | shortest side 8.5 cm |
| `pad:i:j` | 5 × 5 drop pads on the board (i left→right, j far→near), a 5 mm marker each for the system hover | 8.2 cm, 2.5 cm apart |
| `tab:0..2` | turn left / turn right / flip (parallelogram only), on the rail under the board while a piece is selected | 8 × 8 cm, 2.4 cm apart |
| `tray` | the tray floor: the selected piece goes home | whole tray |

A placed (snapped) piece drops its collider: the pad under it answers 「这块放好了」. Snap: a same-kind empty slot whose polygon
holds the pad centre or whose centroid is ≤ 0.95 u from it, and the same orientation (triangles exact, square mod 90°,
parallelogram mod 180° + same face). All input goes through `ui/board/input/BoardInput.kt` (factory board-input template).

## Code
| Path | What |
|---|---|
| `domain/Geometry.kt` | V2, Kind (standard outlines, symmetry), Pose, convex polygon helpers (SAT, clip area) |
| `domain/Puzzle.kt`, `Figures.kt` | figures (generated by `tools/gen_figures.py` from the design package — do not edit), slot poses |
| `domain/Rules.kt` | landing order ① clamp ② snap / turn-me ③ blocked (back off) ④ floating; pads → puzzle points |
| `domain/GameFlow.kt` | the single `PlayState`, taps / turns / flips / drops, undo (T12), hint, help, solved, replay, restore, save |
| `domain/Layout.kt` | every metre: scale, tray homes, board, pads, tabs, plate, volume, eyes (D17 / D35 unit-tested) |
| `ui/board/*` | `BoardScene` (entities, per-frame poses via `BoardFrameSystem`), `Meshes` (extrusions), `BoardTextures`, `BoardScreen` (input wiring) |
| `ui/control/*` | the four pages; every Text logs `OVERFLOW <tag>` when cut |
| `tools/` | `gen_figures.py`, `icons.py` (Material Symbols → vectors), `build_icon.py`, plus Klotski's `contrast.py`, `blank.py`, `loudness.py`, `shots.sh` |

## Build / test (kj-home-pc)
```bash
export JAVA_HOME=~/.pico/primer-cli/jdk/jdk-21.0.12.1+1
./gradlew --offline assembleDebug testDebugUnitTest   # 37 JVM tests: figures, rules, flow, D17 layout, D35 projections, hit replay
python tools/build_icon.py --icon512 <factory>/apps/tangram-wood/icon.png
```
Emulators are shared: borrow with `python -I bin/emu_borrow.py borrow tangram-wood` in the factory, return after.

## Debug broadcast (QA screenshots)
`adb shell am broadcast -a io.embodit.tangramwood.DEBUG -p io.embodit.tangramwood --es cmd <cmd> --es a "<arg>"`. Log tag `Tangram`.
Every command goes through the same taps the volume sends (`routeTap` with a holder name).

## Known
- 3D taps are not reachable by `pico-cli interact` on the emulator: driven by the broadcast through the same calls; the
  three inputs (controller ray, hand ray, eye-hand) need the headset.
- Sounds are SoundPool (not spatial), CC0 wood recordings (factory `apps/tangram-wood/build/sound-sources.md`).
